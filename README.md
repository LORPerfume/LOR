# LOR Perfume

الموقع الرسمي لـ **LOR' Butter Perfume**: https://lorperfume.com

موقع ثابت (HTML/CSS/JS) منشور عبر GitHub Pages من فرع `main`.

## الصفحات
- `index.html`: الصفحة الرئيسية ونموذج الطلب (يُرسل الطلب عبر واتساب)
- `reviews.html`: آراء العملاء
- `privacy.html`, `terms.html`, `cancel.html`, `refund.html`: السياسات

## السعر
25 دينار لكل عبوة (`UNIT_PRICE` في `index.html`).

## الصور
الصور الكبيرة محفوظة بصيغة WebP لتسريع التحميل.
